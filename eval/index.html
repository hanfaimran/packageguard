    Built-In Security Controls
    • KMS Encryption Envelope encryption with customer-managed keys for DynamoDB data at rest, S3 artifacts, and SNS topics.
    • Least-Privilege IAM Strict per-Lambda IAM roles with tightly scoped resource ARNs and minimal permission boundaries.
    • API Key & Rate Limits API Gateway usage plans, quota limits, and API key authentication preventing denial-of-service.
    • Private S3 Bucket Public access block enabled, bucket policy enforcement, and encrypted tarball caching.
    • Point-in-Time Recovery DynamoDB continuous backups (PITR) enabled for data protection and audit record compliance.
